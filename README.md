Finance Copilot

"Connect an ERP in 10 minutes, ask a question in plain English, and get CFO-grade answers, charts, and a PowerPoint—open source.”

Overview
Finance Copilot is an AI-powered assistant for Strategic Finance teams. Connect to QuickBooks, ask a question in natural language, and get SQL, narrative analysis, and downloadable decks.

Roadmap
- ✅ Connect QuickBooks Sandbox
- 🛠️ Build DuckDB + dbt core models
- 🛠️ NL → SQL via LangChain
- 🛠️ Variance analysis + narrative export
- 🛠️ Scenario planning (Monte Carlo)
- 🛠️ Telemetry dashboard

Tech Stack
- Python 3.11, Poetry
- DuckDB, dbt Core
- OpenAI, LangChain
- QuickBooks
- Streamlit, FastAPI, Render
